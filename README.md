# Finanzas JL V2

Aplicación web progresiva para registrar ingresos, gastos, deudas, generar reportes financieros y recibos PDF.

## Funciones principales

- Registro de ingresos
- Registro de gastos
- Control de deudas
- Reporte profesional en Excel
- Recibos PDF
- Perfil del emisor
- Sistema Premium con Firebase
- Instalación como PWA

## Estructura

- index.html: estructura principal
- css/styles.css: estilos
- js/app.js: lógica principal
- js/firebase.js: autenticación y Premium
- service-worker.js: instalación y caché de la app
