# FINANZAS JL V2 - versión separada

Esta versión separa el antiguo `index.html` en:

- `index.html`: estructura HTML de la app.
- `css/styles.css`: estilos visuales.
- `js/firebase.js`: Firebase Auth, Firestore, usuarios, premium y admin.
- `js/app.js`: lógica principal, registros, historial, reportes, recibos, idioma, moneda y PWA.
- `pages/privacidad.html` y `pages/terminos.html`: páginas base legales.

## Recomendación

Sube esta carpeta como nueva rama o repositorio de prueba antes de reemplazar la versión actual.

## Importante

Los íconos `icons/icon-192.png` e `icons/icon-512.png` deben copiarse desde tu versión actual.
